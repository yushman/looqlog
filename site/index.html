▪ looqlog

A timeline for your log file, without uploading it anywhere.

One binary. Point it at a file or pipe a stream into it, and a browser tab opens.

$cargo install looqlog
GitHub Download a binary
MIT ~21 ms cold start Rust + WebAssembly No config, no account

Timeline on top, chips from the fields actually found, table below — one dataset, so narrowing one narrows the others.

One command, then a browser tab

# a file on disk — parsed in the browser, never sent to the backend
$ looqlog /var/log/app.log
  serving on http://127.0.0.1:7891

# a live stream — anything that writes to stdout
$ kubectl logs -f deploy/api | looqlog
$ tail -F /var/log/syslog | looqlog

Measured, not estimated

Every number came off a benchmark or a stopwatch on a real binary, with the command recorded in the devlog.

Filter, and the rest of the shape stays visible

Narrowed to errors. The filtered series is drawn over a muted copy of the whole, so the spike at 14:09 stops hiding in the noise.

A stack trace is one event, not sixty rows

Row 983 carries eight lines. The timeline counts events, so one exception is one bar. Recognition uses explicit frame markers, never indentation alone.

What it reads

Three formats, auto-detected

JSON Lines, logfmt, plain text. Override with #format= when the guess is wrong.

Prefixes it recognises

syslog, klog, Apache/CLF, Docker-wrapped stdout, Android logcat — columns and tag become fields.

Nothing lost quietly

Unparseable lines are skipped and reported. Entries + skipped + blank always equals the total.

Privacy, stated precisely

File mode — never leaves the browser

Read through the File API, parsed by WebAssembly in the tab. The backend never opens it. Kill the network after load and it still works.

Stdin mode — never leaves the machine

Lines cross a localhost WebSocket, guarded by an origin check and a per-process token. That stops another browser tab, not another local process.

Nothing phones home either way. No hosted service, no telemetry, no CDN at runtime, no account.

Use something else when it fits better

Reach for lnav in the terminal

Excellent, a decade of polish, never leaves your shell. Pick looqlog when a drag-to-select timeline beats a keybinding.

Kibana or Grafana, if they are already up

They win the moment logs come from more than one machine. looqlog needs no ingestion and no index.

Not an online log viewer

Pasting production logs into a web form sends them to someone else's server. That is what this exists to make unnecessary.

Three steps

Install. cargo install looqlog, or a binary from Releases. The UI is inside it.
Open something. looqlog app.log, or pipe a stream in. --open launches the browser for you.
Share the view, not the log. Filters and range live in the URL fragment, which never leaves the browser.
