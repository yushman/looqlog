▪ looqlog

Таймлайн для лог-файла, который никуда не надо загружать.

Один бинарник. Даёте ему файл или направляете поток — открывается вкладка в браузере.

$cargo install looqlog
GitHub Скачать бинарник
MIT ~21 мс холодный старт Rust + WebAssembly Без конфигов и регистрации

Сверху таймлайн, слева чипы из найденных полей, снизу таблица — набор данных один, поэтому сужение одного сужает остальные.

Одна команда — и вкладка в браузере

# файл на диске — разбирается в браузере, на бэкенд не уходит
$ looqlog /var/log/app.log
  слушаю на http://127.0.0.1:7891

# живой поток — всё, что пишет в stdout
$ kubectl logs -f deploy/api | looqlog
$ tail -F /var/log/syslog | looqlog

Измерено, а не прикинуто

Каждое число снято бенчмарком или секундомером с живого бинарника, команда записана в devlog.

~21 мсхолодный старт, среднее по пяти прогонам
80 мс/МБразбор файлов на 50–200 МБ
3,6 мсперефильтровать 10 000 записей
36 строкв DOM, пока листаются 50 000

Фильтруете — общая картина никуда не девается

Сужено до ошибок. Отфильтрованный ряд рисуется поверх приглушённого полного, поэтому всплеск в 14:09 перестаёт прятаться в шуме.

Стек-трейс — одно событие, а не шестьдесят строк

В строке 983 — восемь строк. Таймлайн считает события, поэтому одно исключение даёт один столбик. Распознавание идёт по явным маркерам кадров, никогда по одному отступу.

Что читает

Три формата, определяются сами

JSON Lines, logfmt, обычный текст. Если детект промахнулся — задать через #format=.

Узнаёт префиксы

syslog, klog, Apache/CLF, обёрнутый Docker'ом stdout, Android logcat — колонки и тег становятся полями.

Ничего не теряется молча

Неразобранная строка пропускается и сообщается. Записи + пропущенные + пустые всегда сходятся с итогом.

О приватности — точно, без округления

Файловый режим — не покидает браузер

Читается через File API, разбирается WebAssembly во вкладке. Бэкенд его не открывает. Отключите сеть после загрузки — всё продолжит работать.

Режим stdin — не покидает машину

Строки идут по localhost-WebSocket под проверкой origin и токеном на каждый запуск. Это закрывает чужую вкладку, но не другой процесс на той же машине.

Наружу не ходит ничего ни в одном режиме: ни облака, ни телеметрии, ни CDN в рантайме, ни аккаунта.

Когда лучше взять другое

В терминале — lnav

Отличный, десять лет шлифовки, не выдёргивает из шелла. looqlog — когда таймлайн с выделением мышью удобнее горячей клавиши.

Kibana или Grafana, если уже подняты

Они выигрывают, как только логи идут больше чем с одной машины. looqlog не требует ни приёмки, ни индекса.

Но не онлайн-просмотрщик

Вставить продовые логи в веб-форму — значит отправить их на чужой сервер. Ровно это looqlog и позволяет не делать.

Три шага

Поставить. cargo install looqlog или бинарник из Releases. Интерфейс внутри.
Открыть что-нибудь. looqlog app.log или направить поток. --open сам запустит браузер.
Поделиться видом, а не логом. Фильтры и диапазон лежат во фрагменте URL, а его браузер никуда не отправляет.
